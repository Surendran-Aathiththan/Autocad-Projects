# 3D Bottle: Solid Model

A 3D solid model of a bottle built in AutoCAD from a dimensioned reference drawing.

![Bottle reference drawing and 3D view](bottle%203d.png)

The bottle has a 40 mm square body with R5 corners, a Ø20 mm neck, an R15 shoulder transition, an overall height of 130 mm and a 1 mm wall thickness.

## Skills shown

- 3D solid modelling from orthographic views
- Reading dimensioned engineering drawings

## Files

| File | Description |
|---|---|
| `bottle 3d.dwg` | AutoCAD 3D model (AutoCAD 2018 format) |
| `bottle 3d.png` | Dimensioned reference drawing with a 3D view |

Open the `.dwg` in AutoCAD 2018 or later, or view it in the free Autodesk Viewer.
